# YuNet face detector

`face_detection_yunet_2023mar.onnx`（232589 字节）是 OpenCV Zoo 的 YuNet 人脸检测模型，供 `tools/extract_highlight_frames.py` 与 `tools/compose_cover.py` 把人物放到封面右侧。站点构建（`tools/build.py`）不加载这个文件。

- 目录：<https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet>
- 模型：<https://github.com/opencv/opencv_zoo/blob/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx>
- 上游许可：<https://github.com/opencv/opencv_zoo/blob/main/models/face_detection_yunet/LICENSE>
- 训练与论文出处：<https://github.com/ShiqiYu/libfacedetection.train>
